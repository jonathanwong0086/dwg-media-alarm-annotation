# TK*** 图框命名规范与标准尺寸

图框块名统一为 `TK[系列][朝向][加长]`，块插入点位于图框**左下角**。

## 命名字段

| 字段 | 取值 | 含义 |
|------|------|------|
| 系列 | `1` / `2` / `3` | A1 / A2 / A3 |
| 朝向 | `L` / `H` | L=横放(long，长边水平) / H=竖放(high，长边竖直) |
| 加长 | `A` / `B` / `C` | A=原尺寸 / B=长边+1/4 / C=长边+1/2 |

例：`TK1LB` = A1 横放 第二加长档 = 594 × 1051 mm。

## 基础幅面尺寸 (mm)

| 系列 | 长边 | 短边 |
|------|------|------|
| A1 | 841 | 594 |
| A2 | 594 | 420 |
| A3 | 420 | 297 |

加长作用在**长边**上：B = 长边×1.25，C = 长边×1.5。

## 1:100 比例下的模型空间尺寸 (mm × 100)

图纸比例一般 1:100，故模型空间尺寸 = 幅面mm × 100。

| 块名 | 长边(u) | 短边(u) | 说明 |
|------|---------|---------|------|
| TK1LA | 84100 | 59400 | A1 原尺寸 |
| TK1LB | 105100 | 59400 | A1 +1/4，即 594×1051 |
| TK1LC | 126100 | 59400 | A1 +1/2 |
| TK2LA | 59400 | 42000 | A2 原尺寸 |
| TK3LA | 42000 | 29700 | A3 原尺寸 |

## 朝向判定

图框块名里的 `L/H` 标称朝向，但实际摆放需用坐标验证。
`detect_frames.py` 的做法：对每个块同时算横放 `(长,短)` 和竖放 `(短,长)` 两种矩形，
把设备位号往里套，选**全覆盖且图框间零重叠**的朝向。

> 经验：同一批图框若竖向堆叠且 Y 向块间距 = 短边，多半是横放(landscape)。

## 图框作为打印单元

每个 TK 图框对应一张打印图纸。标注**不得跨图框**，且图例/引线/文字
必须全部落在图框四个角点以内。
